# SEO and Google

What the site ships today, and the two steps only the owner can complete.

## Implemented

- **Per-page metadata** on every HTML page: `title`, `description`, `robots`
  (`index,follow,max-image-preview:large`), absolute `canonical`, Open Graph and Twitter
  card tags, and JSON-LD (`Organization`, `WebSite`, `SoftwareApplication` on the landing;
  `WebPage`/`TechArticle` elsewhere; per-page `WebPage` on every demo).
- **`sitemap.xml`** at the apex listing the main pages plus every demo page (generated by
  `tools/gen-demos.js` from `demos/sites.js`; regenerate with `npm run demos`).
- **`robots.txt`** at the apex: allow all, sitemap pointer, and an `AIFeed:` comment
  pointing at `/.well-known/ai.json`.
- **`og-image.png`** (1200×630) generated with the Node standard library only
  (`tools/gen-og-image.js`) — no binary assets checked in.
- **`llms.txt`** for tools that do not speak AIFeed yet.
- Demos already had their own `robots.txt` + `sitemap.xml`; they now also carry the same
  metadata set.

Verify quickly:

```bash
curl -s https://aifeed.md/robots.txt
curl -s https://aifeed.md/sitemap.xml | head -20
curl -sI https://aifeed.md/og-image.png | head -3
```

## Step 1 — Google Search Console (needed for search)

1. Open <https://search.google.com/search-console> and add a **Domain** property
   `aifeed.md` (not the URL-prefix variant).
2. Google shows a TXT record like
   `google-site-verification=XXXXXXXX…`. Copy the whole value.
3. Add it to Cloudflare DNS — either paste the value here and it is added via the API, or
   do it manually: Cloudflare → DNS → Add record → type **TXT**, name `@`, content the
   copied value.
4. Back in Search Console press **Verify**. DNS verification can take a few minutes.
5. Submit the sitemap: **Sitemaps → add** `https://aifeed.md/sitemap.xml`.
6. Optional: **URL Inspection → Request indexing** for `https://aifeed.md/`.

Alternative if DNS is inconvenient: Search Console also accepts an HTML file
(`google<token>.html`) placed at the site root; drop the file into `site/` and it is
deployed as-is.

## Step 2 — Google Analytics (optional)

If you want traffic numbers, create a GA4 property and share the `G-XXXXXXXXXX`
measurement ID. It will be added to the landing page and demo pages only — the
`process.html`/`enforcement-report.html` pages stay fully offline (no external requests,
enforced by tests).

## Notes

- The apex now serves its own signed AIFeed manifest and a `_aifeed` DNS anchor; search
  engine crawlers read `robots.txt` and the sitemap, AI agents read
  `/.well-known/ai.json`.
- `site/{robots.txt,sitemap.xml,og-image.png}` are generated and gitignored; rebuild with
  `npm run demos` (or `npm run verify`).
